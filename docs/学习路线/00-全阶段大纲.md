## 六、代码里有、但**不用学**的东西（模板遗留）

这部分最容易浪费时间。判断依据：**没有前端页面、或者表根本没建**。

| 模块 | 文件 | 为什么不用学 |
|---|---|---|
| 帖子 / 点赞 / 收藏 | `PostController`、`PostFavourController`、`PostThumbController` | 论坛示例，`create_table.sql` 里**根本没建这几张表**，跑不通 |
| 微信公众号 | `WxMpController`、`wxmp/*` | 模板能力，项目没用上 |
| 对象存储上传 | `CosManager`、`FileController` | 需要腾讯云密钥，与主线无关 |
| 测试登录 | `TestSaTokenLoginController` | 调试用 |
| 代码生成器 | `generate/CodeGenerator` | **例外：值得花 30 分钟**，以后写新模块能省一半时间 |

## 七、大纲没写、但面试必问的 12 个点

这些散落在各阶段代码里，不会单独成章，但**每次面试都会问**。用这张表自查：

| # | 知识点 | 在哪个阶段 | 一句话答案 |
|---|---|---|---|
| 1 | 统一返回体 + 错误码 | 一 | 前端只处理一种结构 |
| 2 | 全局异常处理 | 一 | 业务异常统一转 code/message |
| 3 | DTO / VO / Entity 三层 | 一 | 入参、出参、存储解耦 |
| 4 | Long 精度丢失 | 一 | 后端序列化成 String |
| 5 | 跨域 + Cookie | 一 | `allowedOriginPatterns` 不能是 `*` |
| 6 | 逻辑删除的代价 | 一 | 唯一索引冲突、查询要带条件 |
| 7 | N+1 查询 | 一 | 批量查 + 内存拼装 |
| 8 | SSR 与登录态 | 一 | 服务端请求带不上浏览器 Cookie |
| 9 | BitMap 适用边界 | 二 | 只有两种状态、按天/按 id 连续 |
| 10 | ES 与 MySQL 一致性 | 二 | 全量 + 增量 + 改标记而非删文档 |
| 11 | 缓存三兄弟（穿透/击穿/雪崩） | 三 | 空值缓存 / 互斥锁 / 随机过期 |
| 12 | 限流与熔断的区别 | 三 | 限流是"不让进"，熔断是"不调用" |
