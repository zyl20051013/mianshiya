# 签到日历前端

## 自测题

### 面试官提问 1：为什么打卡 hook 挂在 `QuestionCard` 而不是首页？

a：根据现实真实价值来抉择的，不是你登录了就能签到，要去做题才算签到

### 面试官提问 2：`useEffect(() => {}, [])` 和 `useEffect(() => {}, [year])` 的区别？

* **`[]`（空依赖）**：代表这个副作用**只在组件第一次挂载（Mount）时执行一次**。类似于类组件里的 `componentDidMount`。比如我们打卡的 Hook，只要进一次页面，打一次卡就行了。
* **`[year]`（有依赖）**：代表只要 `year` 这个变量的值发生变化，里面的代码就会重新执行一次。比如日历图，用户下拉切换年份时，就会触发重新拉取那一年的数据。

a：dayjs开始是1月1日



### 面试官提问 4：日历图是怎么用“热力图 + 日历坐标系”实现的？

a：这是 ECharts 的一种组合用法。我并没有手动画几百个方块，而是：

1. 配置 `calendar` 坐标系，告诉 ECharts 画哪一年的日历。
2. 配置 `series`，类型选 `heatmap`（热力图），并且把坐标系（`coordinateSystem`）设为 `calendar`。
3. 通过 `visualMap` 配置颜色映射，0 显示灰色，1 显示绿色。
   这样，ECharts 就会自动把数据数组里的 `[日期字符串, 1]`，精准地渲染到对应的日历格子里。


### 面试官提问 5：隐式依赖（dayjs）有什么风险？

a：隐式依赖是指：我的代码里用到了 `dayjs`，但我的 `package.json` 里并没有声明它，只是因为 `antd` 依赖了它，导致它能被 `import` 成功。
**风险在于**：如果未来某天，`antd` 团队觉得 `dayjs` 不好用，把底层换成了别的日期库。我们在执行 `npm install` 更新 `antd` 之后，`dayjs` 就会从 `node_modules` 中消失，导致整个项目直接运行崩溃。
**最佳实践**：只要代码里用到了，就必须在 `package.json` 里显式声明，哪怕它是其他库的传递依赖。
